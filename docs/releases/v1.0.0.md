EVORA brings case management, evidence processing, and investigation tools into one workspace for Windows and Linux x86_64.

- Organize cases and upload documents, images, audio, and video.
- Inspect extracted results alongside their original evidence.
- Explore timelines, relationship graphs, and GPS locations on maps.
- Ask questions about case evidence and inspect the references used.
- Review findings and export reports.
- Manage local accounts, case access, models, and appearance.
- Download incremental updates from Settings, with verification and rollback.

**Installation**

- **Windows:** Download and run `EVORA-Setup-Windows-x64.exe`.
- **Linux:** Download `evora-linux-x86_64.tar.gz`, extract it, and run `install.sh`.

Install the full package to get started. Later updates are available through **Settings → Updates**. Evidence, accounts, and settings are preserved during updates.
