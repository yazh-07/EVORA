Linux x86_64 now supports incremental updates alongside Windows. EVORA downloads only changed application files, verifies them, and offers **Restart and update** in Settings. Failed startups restore the previous application files. Evidence, accounts, and settings are preserved.

**Linux users: download the full Linux package once, extract it, and run `install.sh` to enable the updater.** Future releases can then use smaller downloads. Existing Windows installations with the updater can update normally.

The Linux release includes `EVORA-Update-Linux-x86_64.json` and `EVORA-Update-Linux-x86_64.bin`. Both platforms' update files are covered by `SHA256SUMS`. A full package remains available when incremental updating cannot be used.

This release starts the version sequence at **1.0.0**. Users of previous 1.3.x builds must install the full package once because the version number is lower.
