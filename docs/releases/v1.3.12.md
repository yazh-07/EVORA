Ask uses clearer, conversational replies and distinguishes a model failure from missing evidence. When a model reply cannot be verified, matching source records remain available with explicit source-record labeling. Greetings and basic help work without a model request.

A visible References section shows filenames, quoted excerpts and exact record locations, with links to the original evidence. Used references are distinguished from reviewed records; reviewed records are never presented as support for an unverified answer.

OpenAI-compatible providers can return fenced JSON without losing the existing source validation and independent claim checks.
