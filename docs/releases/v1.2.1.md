# EVORA v1.2.1

Fixes ChatGPT sign-in startup in the Windows application, where EVORA incorrectly rejected its own credential file using Unix permission bits.

Windows now protects the credential directory, temporary files and stored credentials with an explicit private NTFS ACL for the current Windows user and SYSTEM. Existing credential files are secured in place without resetting the host registration, local accounts, case database or evidence vault. Unix owner-only permissions remain enforced on Linux.

Upgrade from v1.2.0 using the new installer or portable bundle, reopen EVORA, then retry **Continue with ChatGPT**. You do not need to run as administrator, manually weaken permissions or delete your data. ChatGPT account eligibility and consent still apply.

The release pipeline now checks credential-file round trips, repair of a legacy ACL, and the signed OAuth callback on native Windows. Both frozen application smoke tests also create an isolated local administrator and start ChatGPT authorization twice, without contacting OpenAI or transmitting evidence.

## Downloads

- Windows installer: `EVORA-Setup-Windows-x64.exe`
- Windows portable bundle: `evora-windows-x64.zip`
- Linux portable bundle: `evora-linux-x86_64.tar.gz`
- Verify downloads against `SHA256SUMS`.

The v1.2.0 multimodal features and their model/OCR accuracy limits remain unchanged. Keep your existing workstation data directory when upgrading. No account credentials or investigator data are included in these packages.
