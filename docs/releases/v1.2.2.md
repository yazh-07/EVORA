# EVORA v1.2.2

Adds **Process all** to the case Evidence tab. Process the case's documents, CSV records, images and video without opening each source individually.

- Includes every evidence page, regardless of library filters.
- Processes one source at a time, skips completed outputs and monitors existing runs instead of duplicating them.
- Shows per-file progress, failures, skipped sources and unconfirmed outcomes. One malformed source does not hide other results.
- Optionally includes image descriptions, OCR and sampled video scene analysis using the configured image-capable model. Hosted media processing requires explicit destination consent.
- Uses 5-second video sampling with a 12-frame cap; batch speech transcription is off. Standalone audio retains the individual transcription workflow.
- Stops future requests when you stop the queue, leave the Evidence tab or change sessions. Already accepted server work may continue. Keep the Evidence tab open while the browser queue runs.

After installing, open **Evidence → Process all**, choose whether to include descriptions/OCR, then click **Start batch**. After completion, run case analysis to include the outputs. Existing cases, local accounts, evidence originals and ChatGPT credentials are preserved. The v1.2.1 Windows credential-permissions fix is included.

Regression checks cover 105 synthetic originals across multiple evidence pages, real extraction lineage, malformed-input isolation and duplicate prevention. The frontend suite and desktop/mobile browser checks cover the new controls. These checks do not establish model accuracy; compare derived outputs and citations against originals.
