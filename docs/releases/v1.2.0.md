# EVORA v1.2.0

- Connect an eligible ChatGPT plan through **Continue with ChatGPT**, without manually entering an API key.
- Describe images and extract visible text with the selected multimodal model or a separate vision model.
- Analyze capped video-frame samples with timestamps, descriptions, OCR and candidate tracks.
- Fetch provider models and advertised image capabilities, with improved OpenRouter diagnostics.
- Preserve original files, processing history, source-backed graph relationships and evidence citations.
- Reject invalid image bytes before analysis creates a run. Tighten Q&A citation validation and label model-derived claims.
- Prevent uniform-image hallucinations with a local pixel check; improve offline settings and report/export checks.

Validation: 908 backend tests, 382 frontend tests, 124 script checks, twelve integration/browser workflows and production build passed before release preparation. Packaged binaries additionally run frozen application/model-worker smoke checks on their native build runners.

## Downloads

- Windows installer: `EVORA-Setup-Windows-x64.exe`
- Windows portable bundle: `evora-windows-x64.zip`
- Linux portable bundle: `evora-linux-x86_64.tar.gz`
- Verify downloads against `SHA256SUMS`.

Existing local accounts remain separate from ChatGPT authorization. Keep your workstation database, evidence vault and companion private credential directory when upgrading. No investigator data or credentials are included in these downloads.

Model output and OCR require human verification. Video analysis covers sampled frames, not continuous coverage or verified identity. Speech requires a separately configured local runtime/model and is not bundled. Internet and eligible plan access are required for ChatGPT inference; local login and supported local processing remain available offline.
