# EVORA v1.3.1

Windows installers and portable packages now bundle a private Neo4j Community runtime and Java. Install EVORA and open it without Docker or a separate graph database installation.

- Pinned Neo4j 5.26.30 and Eclipse Temurin Java 21.0.13+9, verified by SHA-256 at build time.
- Automatic authenticated startup on a private loopback port, with HTTP/HTTPS and usage reporting disabled.
- Graph data and generated credentials retained under `%LOCALAPPDATA%\EVORA\graph` across upgrades and normal uninstall.
- Graceful backend/JVM shutdown, owner-death monitoring and exclusive graph-home locking.
- Original runtime licenses and corresponding source archives included in the package.
- Blue documentation screenshots retained from the workspace refresh.

Local checks cover real-JVM authentication, persisted data/credentials on restart, a second-owner rejection, clean owner-death shutdown, archive checks and secret-safe errors. The Windows desktop supervisor cross-compiles successfully. The native frozen smoke test now requires synthetic GPS processing, completed case analysis and graph readback before assets are published.

Linux/source deployments continue to use external Neo4j. Existing external graph stores are not imported automatically; external mode remains available. See [bundled graph documentation](https://github.com/yazh-07/EVORA/blob/main/docs/bundled-graph.md).

Native release assets are valid only after the Windows/Linux build and smoke workflow succeeds. Optional plate OCR models/runtime remain a separate explicit installation.
