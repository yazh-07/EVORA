Windows updates can now download only changed application files, reusing unchanged libraries and bundled runtimes. Settings shows the download size and changed-file count, with a **Restart and update** action when the update is ready.

Downloads are verified and resumable. The updater closes EVORA, installs the verified files, and checks that the new version starts. If startup fails, it restores the previous application files. Evidence, accounts, and settings are preserved. A full installer remains available when incremental updating cannot be used.

**Install this version using the complete Windows setup once to enable smaller future updates.** Linux and portable installations continue to use their existing download flow.
