# EVORA v1.3.0

A redesigned investigation workspace with direct evidence processing, source inspection, geographic maps and optional local plate OCR.

## Changes

- Cleaner case navigation, larger conventional typography, customizable appearance and responsive layouts.
- Process pending or selected files directly, with explicit reprocessing, compact progress and scoped retries.
- Consolidated Results / Original / Info source views, verified excerpts and historical citations across result pages.
- Locations workspace with street and satellite basemaps, GPS clusters, source links, date/device filters, playback and conservative recorded paths.
- Street View links open Google's available panorama for a reported GPS point. Approximate place mentions remain explicitly labeled.
- Street maps load online by default. Offline map selection is remembered and uses bundled country outlines or a local PMTiles file. Map choices do not change local model settings.
- Optional isolated local plate detector and OCR, explicit artifact installation and recorded model provenance. Reprocess existing media for new readings.
- Refreshed README screenshots using synthetic cases and GPS points.

## Validation

414 frontend tests pass, with production build and API/type checks. Targeted backend checks passed 55 tests with one environment-specific skip. Browser checks cover the investigation flow, mobile layouts, source/media inspection and live street/satellite tiles. A disposable local-account case completed processing and real Neo4j analysis.

## Limits and installation

Street and satellite tiles require internet access. Google panorama availability and imagery dates vary. Local PMTiles archives are session-scoped. Plate smoke checks cover one public sample and a negative image; they do not establish regional accuracy. Dense video plate tracking and consensus remain future work.

For local plate OCR, use `scripts/setup-plates.sh` with its separate Python environment, then restart and reprocess selected media. Optional plate models and their isolated runtime are not bundled in native release assets.

## Distribution status

This is a prerelease. GitHub source archives are available immediately. Linux and Windows binaries and checksums are attached by the release workflow only after native build and smoke checks pass. Until those assets appear, use the source setup instructions; binaries from previous versions do not contain these changes.
