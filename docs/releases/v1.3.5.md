# EVORA v1.3.5

Smaller Windows packages while retaining bundled Java, Neo4j, local text extraction and the existing investigation workflow.

- Build a compressed Java 21 runtime image with Java SE and Neo4j service/security modules instead of shipping the full JDK. Compiler tools, development modules, headers and the duplicate Java source ZIP are no longer installed.
- Remove Neo4j Browser, labs and unused distribution launchers. EVORA still manages its private graph through the packaged Java entry points.
- Prevent optional training/notebook/plotting frameworks from being collected into the Python executable. Core spaCy, NumPy, OpenCV, cryptography and SQLite components are retained.
- Preserve runtime notices/legal files and the corresponding upstream source archives.

No investigation-time runtime download or separate Neo4j/Java installation is introduced.
