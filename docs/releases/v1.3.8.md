EVORA now remembers the saved local/online mode, provider, models and update preferences after sign-in. Model API keys stay in the account-encrypted workstation database. Windows upgrades preserve the existing launcher configuration.

Settings → Updates checks for new releases. Windows installations can download, resume and verify the installer before opening setup. Installation waits for evidence processing and case analysis to finish. Linux and source installations link to the release download. Automatic checks can be switched off; installation always requires an administrator action.

Light mode uses a cool gray background with matching neutral surfaces, while retaining customizable accent colors.
