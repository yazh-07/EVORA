# EVORA v1.2.3

Adds case-wide evidence processing, header activity tracking and a clearer investigation graph, with corrections to extraction and executive-brief context selection.

## Process all and activity

Open **Evidence → Process all → Start batch** to process sources from every evidence page. Completed outputs are skipped, existing runs are monitored, and per-file progress/errors remain visible. Optional image descriptions, OCR and sampled video scenes use the configured image-capable model and require explicit external-destination consent. Batch video samples every 5 seconds with a 12-frame cap; speech transcription is off. Standalone audio retains its individual transcription workflow.

The header **Activity** bell shows the running case, current filename, progress and waiting work. Batches continue across tabs and cases. **Stop queue** prevents remaining files from starting; already accepted server work may still finish. It does not cancel a running server job. Closing/reloading the app window or signing out stops future queue requests. The panel tracks Process all batches; individual processing and case-analysis jobs retain their own status controls.

## Analysis and graph corrections

- Default graph groups exact identifiers and reported coordinates. File nodes, raw events, dates and unverified visual candidates remain available under **Show all source records**. Grouping does not verify physical identity.
- Detector region matches no longer become person/vehicle types. Raw geometry, frame/time locators, detector labels and scores remain available as unverified visual candidates.
- Valid source-backed IP assignments and GPS location relationships retain their citations. Provenance rays remain distinct from substantive graph edges.
- Repetitive identifier findings are consolidated. Alternate detector views with identical subjects/citations are folded while retaining their individual inspection and review controls.
- Executive briefs prioritize primary document lines, structured fields, OCR and scene descriptions over detector/provenance noise. Source selection is bounded and coverage is explicit; the model does not necessarily receive every observation.
- Text extraction filters filename-only and technical-abbreviation predictions, prefers full ISO date literals and uses local role context to improve name classification.
- Mobile CSV headers are recognized. Existing document uploads can be explicitly reinterpreted as a supported structured CSV format without re-uploading or changing original bytes, uploaded metadata or previous runs. The UI restores the latest successful interpretation.
- Grouped/source graph transitions reinitialize motion safely, including reduced-motion mode. Empty grouped views still provide access to full source records.

In the synthetic Harborlight demo, the corrected default graph showed 17 grouped nodes and 11 relationships, retaining all five IP assignments and five location relationships. Findings displayed as 11 cards with 18 underlying records, and the brief correctly reported the 09:12 cancellation and 10:30 refund. These are demo results, not a general accuracy guarantee. Originals and previous processing/analysis history were preserved.

Includes the v1.2.1 Windows ChatGPT credential-permissions fix. Existing local accounts, cases, evidence originals and saved ChatGPT credentials are preserved when upgrading. Model-derived output and citations still require comparison with originals.
