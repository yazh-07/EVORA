# EVORA v1.2.3

Adds a header **Activity** icon for the Process all evidence queue. Click the bell to see the case, current filename, progress, waiting files and sources needing attention. Use **Stop queue** from the panel to prevent remaining files from starting.

Batches now continue while switching tabs or cases. Returning to Evidence restores the same batch and results. The queue belongs to this app window and local authenticated session: closing/reloading the window or signing out stops future requests. Already accepted server work may still finish. Stop queue does not cancel a running server job. This activity panel tracks Process all batches; individual processing and case-analysis jobs retain their existing status views.

Includes v1.2.2's Process all controls: all evidence pages, completed-run skip, existing-run monitoring, per-file progress/errors and optional batch image descriptions/OCR/video scene interpretation with explicit external-provider consent. Batch video samples every 5 seconds, up to 12 frames, with speech transcription off. Standalone audio retains its individual transcription workflow. Run case analysis after processing to include the completed outputs.

Includes the v1.2.1 Windows ChatGPT credential-permissions fix. Existing local accounts, cases, evidence originals and ChatGPT credentials are preserved. Compare model-derived output and citations against originals; no model accuracy guarantee is implied.

Validation includes the frontend suite, the real-backend 105-file bulk-processing regression, activity-store/session lifecycle tests, and desktop/mobile browser checks covering navigation, current-file display, queue stopping and resume without duplicate completed runs.
